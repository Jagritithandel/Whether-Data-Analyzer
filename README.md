# Weather Data Analyzer

## About
Weather Data Analyzer is a beginner-friendly Python project that stores and analyzes weather records of multiple cities using tuples. It displays temperature and humidity, finds the hottest and coldest cities, and sorts cities by temperature.

## Features
- Stores weather records using nested tuples.
- Displays city names, temperatures, and humidity levels.
- Finds the hottest city using `max()`.
- Finds the coldest city using `min()`.
- Sorts cities by temperature using `sorted()`.

## Technologies Used
- Python 3

## Concepts Used
- Tuples and Nested Tuples
- For Loops
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Functions
- String Formatting

## How to Run
1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python weather_data_analyzer.py
```

## Purpose
This project helps beginners practice Python tuples, loops, lambda functions, and built-in functions through a simple weather data analysis program.
